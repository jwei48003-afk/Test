# Code Tab QA Sample App

This disposable repo fixture is for human QA of Code Tab's GitHub/repo workflows.

## What it is

A static feature-request dashboard with sample data in `feature-requests.csv`. Requests can be filtered by priority and status.

## How to run

Open `index.html` in a browser. No server, build step, or dependencies are required.

## QA task

Ask Code Tab to review the repo and add a status filter while preserving the existing priority filter.
